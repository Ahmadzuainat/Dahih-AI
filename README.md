# Dahih AI (الدفعة - الدحيح AI)

A full-stack AI-powered study and educational platform designed for students.

## 📁 Repository Structure

```
Dahih-AI/
├── Frontend/          # React + Vite frontend application
│   ├── src/           # Components, pages, context, and services
│   ├── server/        # Demo server & mock data
│   ├── scripts/       # Helper scripts
│   ├── index.html
│   ├── vite.config.js
│   └── package.json
│
└── Backend/           # Express / Node.js backend services
    └── .gitkeep
```

## 🚀 Getting Started

### Frontend Development

```bash
cd Frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.
